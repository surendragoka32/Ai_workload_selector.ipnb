# AI Workload Selector

## Project Overview
A Python-based application that recommends suitable AI solutions based on business requirements.

## Technologies Used
- Python
- Google Colab
- Microsoft Azure AI concepts

## Features
- Identifies AI workloads
- Recommends suitable AI services
- Explains the reason behind each recommendation

## AI Solutions Covered
1. Large Language Models (LLM)
2. Azure AI Document Intelligence
3. Azure AI Translator
4. Computer Vision
5. Azure AI Speech
6. Azure AI Search

## How to Run
1. Open the Google Colab notebook.
2. Run the Python code cells.
3. Enter a business requirement.
4. View the recommended AI solution.
